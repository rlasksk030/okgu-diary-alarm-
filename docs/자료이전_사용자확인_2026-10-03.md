# 지금 필요한 사용자 확인 — 원본 백업 확보 후

이미 제공한 시트 ID·사진 원본/사본 대응·서버 코드·푸시 비밀값·백업 ZIP·Cloudflare/GitHub 인증은 다시 제공하지 않아도 됩니다. 운영 전환/속도/복구 한계 승인은 유효합니다.

방금 작성한 일기는 사용자가 기존 Google 시트에서 확인했으므로 보존돼 있습니다. 현재 공개 앱 저장/교사 조회는 모두 GAS이며 교사 표시 누락 원인은 아직 확정하지 못했습니다. 작성 중인 내용을 보존하고 **대시보드 → 피드 → 전체 → 새로고침**한 뒤 새 기록/기존 기록 표시 여부만 알려주세요. 이름·본문·PIN은 보내지 마세요.

필수 항목은 아래 두 가지입니다.

1. **최신 자료**: 이번 ZIP을 만들어 준 Google 연결 대화/도구에 아래 문장을 전달하고 새 ZIP을 이 대화에 첨부하세요. 옛 백업 사본을 다시 압축하면 새 일기가 포함되지 않습니다.

   > 이전에 백업한 옥구의 운영 원본 시트와 원본 사진 폴더를 다시 읽기 전용으로 백업해 주세요. 모든 시트의 원시 셀/헤더/표시 값/날짜, 원본 사진 bytes, 원본 Drive ID↔사본 ID/파일 대응표, 캡처 시각과 완료 여부를 포함한 새 비공개 ZIP이 필요합니다. 오늘 원본 시트에는 있지만 교사 피드에는 안 보이는 일기도 포함해 주세요. 원본과 운영 트리거를 수정하거나 공개 공유하거나 쓰기를 중단하지 마세요. 이전과 동일한 형식으로 주세요.

2. **현재 운영 서버/예약 상태**: [Apps Script](https://script.google.com/home) → 기존 운영 서버 프로젝트 → **배포 → 배포 관리 → 사용 중인 웹 앱**에서 현재 버전과 처음 첨부 코드가 같은지 확인해 “동일, 버전 N”만 알려주세요. 다르면 해당 버전 코드 파일만 비공개로 첨부하세요. **프로젝트 설정**의 시간대, **트리거**의 `scheduledDiaryReminderPush` 존재/개수/시간, **실행**의 최근 실행 상태도 알려주세요. 아직 수정·삭제·새 배포·미작성 알림 테스트 실행은 하지 마세요. 비밀번호/API 키/PIN을 채팅에 넣지 마세요.

최신 캡처 경로를 확인한 뒤 실제 동결 시점의 최종 자료를 다시 확보해 추가·수정·삭제를 반영합니다. 운영 쓰기는 아직 중단하지 않았습니다. 기존 GAS 시간대/예약 정보를 확인해야 같은 날 중복 없이 새 22시 작업으로 전환할 수 있습니다.

사진 68개와 일기 사진 참조 37개는 이미 대조했고 연결 누락 0입니다. 원본 ID와 사본 ID 대응도 확보했으므로 폴더 링크/파일 ID를 다시 요구하지 않습니다. 원본 댓글/좋아요의 일부 부모 부재는 원문 archive 보존으로 처리했고 추측 연결/삭제하지 않았습니다.

실물 휴대전화/PWA 시험과 승인된 선생님 기기 알림 1건의 식별·수신 확인 순서는 [최신 진행 문서](실자료백업_알림_진행상태_2026-10-03.md)를 따릅니다. 서버 발송 성공과 실물 수신은 별도로 확인합니다. 실물 기기를 특정하지 못해 아직 발송하지 않았고 학생 전체 시험 알림은 보내지 않습니다.

현재 Google 연결이 이 Codex 환경에 없으므로 Google 로그인 재시도를 요구하지 않습니다. 기존 ZIP을 만든 도구가 Apps Script를 실행한 것은 아닙니다. 새 백업 Apps Script는 대체 경로이며 실제 Google 실행/다운로드 첨부 전달은 확인하지 않았습니다.
