# 지금 운영 전환을 막는 항목만

운영 승인은 유효합니다. **기존 GAS 교사 진단 JSON과 원인 규명은 전환 필수 조건에서 제외합니다.** 새 서버에서 원본 기록의 값/권한/조회/표시가 정상임을 검증하면 전환합니다. 이미 받은 코드·ID·사진 대응·ZIP·비밀값/인증은 재요청하지 않습니다.

[Chrome Google 연결 환경에 붙여 넣을 단일 지시문과 소유자 클릭 순서](Chrome_Google연결_최종이전_지시문.md)를 따릅니다. 한 문서로 자료 담당과 설정 담당을 구분했습니다.

1. **최종 수집 경로 확인**: 이전 ZIP을 만든 Google 연결 대화에 지시문 전체를 붙여 넣습니다. 원본 전체/사진을 읽고 최종 ZIP을 전달할 수 있는지만 먼저 확인하며 새 ZIP을 반복 제출하지 않습니다. 이 Codex 환경에는 Google 연결이 없어 직접 수행할 수 없습니다.
2. **기존 GAS 쓰기 차단·예약/실행 확인**: 그 환경이 접근할 수 없는 부분만 소유자가 Apps Script **배포 관리/프로젝트 설정/트리거/실행**에서 처리합니다. 공개 오프라인 도구로 비밀값을 전송하지 않고 기존 코드에 28개 차단 검사를 넣습니다. 기존 배포 URL을 유지해야 오래 열린 학생 앱도 추가 저장이 거절됩니다. 최종 수집 경로/새 서버 준비 전에 동결하지 않습니다. 코드가 동일하면 다시 제출하지 않습니다.
3. **동결 후 최종 A/B 자료를 한 ZIP으로 전달**: 진행 중 저장·사진·알림이 종료됐고 차단 응답이 확인된 뒤 전체 캡처 A/B·사진 bytes·원본ID 대응·실행 journal을 한 번 첨부합니다. 전체 B와 이전 백업을 대조해 추가·수정·삭제를 반영하고 운영 D1/R2 대조 후 기존 Pages로 전환합니다.

이유: 쓰기가 열린 상태의 ZIP 하나로 이후 작성분을 보장할 수 없고, old 예약/진행 중 발송 상태 없이 new 예약을 켜면 중복될 수 있습니다. 최신 자료가 없다고 빈 데이터로 전환하지 않습니다. 별도 시험이나 같은 접근 실패를 반복하지 않습니다.

현재 **운영용 API/D1/private R2는 준비됐지만 연결 전환은 안 됐습니다.** API `https://okgu-diary-api.rlasksk030.workers.dev`, D1장벽1/WRITE_MODEpaused/PUSHdisabled/cron0/계정·일기0입니다. 기존 학생 주소/운영 main/기존 GAS·원본은 그대로입니다. 새 첨부 student-api (3).zip은 학습 TypeScript 코드로 판별했고 학생 백업이 아니므로 적용하지 않았습니다.
